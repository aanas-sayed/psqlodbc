Building psqlODBC for Windows ARM64

This page describes how to build the PostgreSQL ODBC Driver for the Windows ARM64 architecture. ARM64 support is a fork-specific addition; the upstream psqlODBC project does not yet ship ARM64 binaries.

Background

There is currently no official EDB/EnterpriseDB installer that ships an ARM64 build of libpq for Windows. As a result, ARM64 builds require either:

  • Building PostgreSQL (or at minimum libpq) from source for ARM64, or
  • Obtaining a pre-built ARM64 libpq from another trusted source.

The GitHub Actions CI workflow in this fork handles this automatically by cross-compiling libpq from the PostgreSQL source. See .github/workflows/main.yml (the build-postgres-arm64 job) for the exact steps.

Prerequisites

  • Visual Studio 2022 (v143 toolset) with the MSVC ARM64 build tools component installed. The ARM64 target requires at minimum toolset v143; the older v120_xp toolset used for x86/x64 does not support ARM64.
  • ARM64 libpq — the PostgreSQL client library and headers compiled for ARM64. See the section below on obtaining this.
  • WiX Toolset v6 (optional, required only for building the installer). Install via: 
    dotnet tool install --global wix --version "6.*"
wix extension add --global WixToolset.UI.wixext/6.0.0

Obtaining ARM64 libpq

Option A: Build from source (recommended)

This is the method used by the CI workflow. You need a cross-compilation toolchain (MSVC amd64_arm64) and meson/ninja. 

  # Install build tools
  python -m pip install meson ninja

  # Check out PostgreSQL source
  git clone --branch REL_18_STABLE https://github.com/postgres/postgres.git
  cd postgres

  # Set up MSVC amd64_arm64 cross-compilation environment, then:
  meson setup buildarm64 --cross-file arm64-msvc.ini ^
        -Dssl=openssl ^
        -Dextra_lib_dirs=<path-to-arm64-openssl>\lib\VC\arm64\MT ^
        -Dextra_include_dirs=<path-to-arm64-openssl>\include ^
        --prefix=D:\postgresqlarm64

  meson compile -C buildarm64 src/interfaces/libpq/libpq:shared_library

  # Collect the files needed by the ODBC driver build
  mkdir D:\postgresqlarm64\lib D:\postgresqlarm64\bin D:\postgresqlarm64\include
  copy buildarm64\...\libpq.lib D:\postgresqlarm64\lib\
  copy buildarm64\...\libpq.dll D:\postgresqlarm64\bin\
  xcopy /s src\include D:\postgresqlarm64\include\

The arm64-msvc.ini cross-file should contain: 

  [host_machine]
  system = 'windows'
  cpu_family = 'aarch64'
  cpu = 'arm64'
  endian = 'little'

Option B: Extract from a CI artifact

Download the ARM64 libpq from a successful CI run of the build-postgres-arm64 job in this repository, if available.

Configuring the Build

Edit (or create) winbuild\configuration.xml and set the <arm64> section to point to your ARM64 libpq directories: 

  <arm64>
    <libpq version="">
      <include>D:\postgresqlarm64\include</include>
      <lib>D:\postgresqlarm64\lib</lib>
      <bin>D:\postgresqlarm64\bin</bin>
    </libpq>
    <setvcvars></setvcvars>
    <build_macros></build_macros>
    <runtime_folder></runtime_folder>
  </arm64>

Unlike x86 and x64, there is no "default" path for ARM64 — paths must be set explicitly. The build will fail with a clear error if they are missing.

Building

Open a PowerShell prompt with the MSVC ARM64 (or amd64_arm64) environment active, then run: 

  cd <psqlodbc-source-dir>
  .\winbuild\BuildAll.ps1 -Platform ARM64

To build only ARM64 (skipping x86 and x64): 

  .\winbuild\BuildAll.ps1 -Platform ARM64 -Configuration Release

The output DLLs are placed under: <source>\arm64_Unicode_Release\ and <source>\arm64_ANSI_Release\.

Building the Installer

  .\installer\buildInstallers.ps1 -cpu arm64

This produces installer\arm64\psqlodbc_arm64.msi and psqlodbc_arm64.msm.

CI / Automated Releases

Pushing a tag matching REL-* to this fork triggers the full CI pipeline, which:

  1. Cross-compiles ARM64 libpq from the PostgreSQL source.
  2. Builds and packages ARM64 psqlODBC.
  3. Creates a GitHub Release containing x86, x64, and ARM64 installers.

No local setup is required to produce release artifacts; just push a tag.
